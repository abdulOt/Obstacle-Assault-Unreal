# 🎮 Obstacle Assault (Unreal Engine 5 C++)

A third-person obstacle course game developed in **Unreal Engine 5** using **C++**. This project demonstrates gameplay programming, actor interactions, moving and rotating platforms, character movement, collision systems, and level design fundamentals.

> **Note:** This repository contains the project's **C++ source code** only. Unreal Engine assets, Marketplace content, and generated project files have been omitted to keep the repository lightweight and comply with asset licensing.
